# Fonts

Shared pack typefaces for all three systems:

- `Raleway.ttf` — Material UI; website wordmark and chrome
- `CrimsonText-Regular.ttf`, `CrimsonText-Italic.ttf`, `CrimsonText-SemiBold.ttf` — website editorial (not used in Material)

Do not add a third typeface or swap these roles. Specimens that load `url("fonts/...")` need a local `fonts/` directory next to the HTML; copy or symlink this folder there to preview.
