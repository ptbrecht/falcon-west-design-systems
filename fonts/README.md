# Fonts

Material UI typeface:

- `Raleway.ttf` — Material UI (apps / CRM / Tools)

Do not add a third typeface or swap this role. Specimens that load `url("fonts/...")` need a local `fonts/` directory next to the HTML; copy or symlink this folder there to preview.

Website editorial faces (Crimson Text) live on `cursor/design-systems-seed-f27f` and are not used in Material.
